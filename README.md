# SEAConnect

SEAConnect is a web app for the **Students of East Africa (SEA) at UTSA**.

It provides a central place for members to stay connected, view events, meetings, announcements, and manage their profiles.

## Features

* 🔐 User authentication
* 🏠 Member dashboard
* 📅 Events
* 🤝 Meetings
* 📢 Announcements
* 🌍 SEA member directory
* 👤 User profiles
* 🛠️ Admin panel for officers
* 🔔 In-app notifications
* 📱 Mobile-friendly design

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* Supabase
* Vercel

## Development

Run the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
